# InterceptLauncher
I came up with the idea for InterceptLauncher from a hackathon I went to. We made a project called [AstroShield](https://github.com/dbanerjee622/AstroShield), which detects space debris heading towards either satellites, spaceships, space stations, etc., and launches an intercept to knock it off course. This is were Intercept Launcher comes in.

So this is a gimbal based device that is a prototype of launcher we would integrate into AstroShield. The gimbal allows it to turn to any angel, by first turning one ring for one axis, and then turning the other ring on the other axis.

There are two NEMA17 stepper motors for each of the rings. The first is located in the based and turns the outermost ring. The second in the hub connecting the inner and outer rings on the left. The connecting piece on the right houses a bearing, which turns passively with the stepper motor.

The tube in the middle is used to represent where the actual launch mechanism would go. It would work best with a coilgun, since that can be very accurate and achieve very fast velocities, although one could attach any piece they wanted there that suits their project best.
